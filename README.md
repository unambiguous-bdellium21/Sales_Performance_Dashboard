## 🧭 Overview

Sales_Performance_Dashboard is an Excel and Power BI dashboard for sales analysis. It helps you view sales, profit, customer segments, regions, and product categories in one place.

Use it to spot trends, compare performance, and review key numbers without sorting through raw data.

## ✨ What this dashboard shows

- Total sales and profit
- Sales by region
- Sales by category
- Customer segment performance
- Time-based trends
- KPI cards for quick review
- Charts and filters for clear analysis

## 💻 What you need

- Windows 10 or Windows 11
- Microsoft Excel
- Power BI Desktop
- A mouse and keyboard
- Enough space to store the project files

## 🛠️ How to use it on Windows

1. Open the download page in your browser.
2. Download the repository files to your PC.
3. If the file downloads as a ZIP file, right-click it and choose Extract All.
4. Open the extracted folder.
5. Look for the Excel file or the Power BI file in the project folder.
6. Double-click the Excel file to review the data model, charts, and sheets.
7. Double-click the Power BI file to open the dashboard in Power BI Desktop.
8. Wait for the report to load.
9. Use the filters to switch between dates, regions, categories, and customer segments.
10. Move between report pages to review sales, profit, and trend views.
